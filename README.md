# 💸 Expense Tracker

A personal expense tracker web app to manage daily income and expenses.

## 🔥 Features
- Add income and expense transactions
- Filter by category (Food, Transport, Shopping, etc.)
- Live donut chart showing income vs expense ratio
- Bar chart of top spending categories
- Data saved in localStorage — persists after closing browser
- Fully responsive — works on mobile and desktop

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- localStorage API
